# 50.033 Lab

## Description

My implementation of the SUTD 50.033 Game Development and Design labs: https://natalieagus.github.io/50033

Covers Weeks 1-5: Unity basics, animation, Input System + AudioMixer + Observer pattern, multi-scene + Singletons + ScriptableObjects + Coroutines, and ScriptableObject Game Architecture (SOGA) with pluggable FSM.

## Labs

- Week 1: Unity for Newborns — layout, scenes, prefabs, Rigidbody2D/Collider2D, UI, lifecycle, onClick
- Week 2: Unity for Babies — animator, camera movement, animation events, SFX, prefabs
- Week 3: Unity for Toddlers — Input System, AudioMixer, Observer, Delegates/Actions/UnityEvent
- Week 4: Unity for Children — multi-scene, Singletons, Coroutines/async, ScriptableObjects
- Week 5: Unity for Teens — SOGA events/data, pluggable FSM (State/Action/Decision/Transition)

## Tools and Technology

- **Unity 6** - Game engine
- **C#** - Gameplay scripting
- **Unity Input System** - Keyboard/mouse, ActionMaps
- **URP** - Render pipeline

## Course

SUTD 50.033 Game Development and Design, Fall 2026 exchange term. Lab docs: https://natalieagus.github.io/50033/docs/syllabus
